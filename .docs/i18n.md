# Internationalisierung (i18n)

Übersetzungen ohne Build-Schritt: Kataloge als Go-Map oder JSON (`go:embed`).

## Paket

```go
import "github.com/LukasLow/dreego/v0/pkg/i18n"
```

## Katalog als Go-Map

```go
bundle := i18n.New(i18n.Config{
	Default: "de",
	Messages: map[string]map[string]string{
		"de": {"login.title": "Anmelden", "welcome": "Hallo {name}"},
		"en": {"login.title": "Sign in",  "welcome": "Hello {name}"},
	},
})
app.SetI18n(bundle)
```

## Katalog als JSON (empfohlen)

`locales/de.json`:

```json
{
  "login.title": "Anmelden",
  "mails.one":   "{n} Nachricht",
  "mails.other": "{n} Nachrichten"
}
```

```go
//go:embed locales/*.json
var localeFS embed.FS

bundle, err_open := i18n.Open(localeFS, "locales", "de")
if err_open != nil {
	log.Fatal(err_open)
}
app.SetI18n(bundle)
```

Jede Datei `de.json` / `en.json` ist ein flaches Schlüssel/Wert-JSON.

## Im Handler

```go
c.Locale()                       // z. B. "en"
c.T("login.title")               // "Sign in"
c.Text("login.title")            // derselbe Text als d.Node (für Elemente)
c.T("welcome", i18n.Args{"name": "Lukas"})
c.Tn("mails", 5)                 // Plural: nutzt .one / .other
```

## Locale-Auflösung

In dieser Reihenfolge:

1. **Cookie `lang`** — die ausdrückliche Nutzerwahl.
2. **`Accept-Language`** — q-sortiert, mit Primärsprachen-Match
   (`de-DE` passt auf `de`).
3. **Default** der App (`app.SetDefaultLocale("de")` oder das `Default` des
   Bundles).

## Platzhalter

- `{name}` wird aus `Args` ersetzt.
- Ein **unbekannter** Platzhalter bleibt sichtbar statt zu verschwinden.

## Fehlende Schlüssel

Auflösung: gewünschte Locale → Default-Locale → **der Schlüssel selbst**. Nie
eine leere Zeichenkette. So sieht man sofort, was fehlt.

## Plural

```go
c.Tn("mails", 1)   // -> mails.one
c.Tn("mails", 5)   // -> mails.other
```

Fehlen die Varianten, fällt es auf den Basisschlüssel zurück.
