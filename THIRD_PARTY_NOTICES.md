# Third-party notices

dreego itself has **no runtime dependencies** — everything (routing, session,
CSRF, i18n, markdown, scoped CSS, static, gzip, error pages, the DOM layer) is
written in the Go standard library plus dreego's own code.

---

## gomponents — inspiration, not a dependency

- **Project:** gomponents — https://github.com/maragudk/gomponents
- **License:** MIT — Copyright (c) Maragu AG / Maragu ApS
- **Role in dreego:** *design inspiration* for the idea "HTML as Go functions".
  gomponents is **not** imported, linked, or shipped by dreego.

dreego's own `dom` package (`pkg/dom`) is an independent implementation of that
idea. It was written from scratch to fit dreego's model — in particular so that
**every attribute is a node**, which lets an htmx layer (`hx-*`) live in the same
model without a special case. The exported type is named **`View`** (chosen for
clarity over `Node`). The HTML elements/attributes are generated by
`internal/gen_dom`.

Because no gomponents code is copied into dreego, no gomponents license text
needs to be distributed with dreego. The credit above is given freely, as
thanks for the inspiration.

---

## Historical note

Earlier pre-release versions of dreego wrapped gomponents in a `dom` package and
declared `maragu.dev/gomponents` as a dependency. That dependency has been
**removed**; dreego now compiles with zero external modules.
